LINVA INTERIORS — SUPABASE CRM SETUP

1. The `leads` table has already been created in the Supabase project.
2. In Supabase Dashboard, open Authentication → Users and create an admin user for the CRM (email + strong password).
3. Do not put the service-role/secret key in the website.
4. Deploy this website to GitHub Pages over HTTPS.
5. Open /crm/ and sign in with the Supabase Auth user.
6. Test: Free Home Visit, Design Discovery Quiz and Budget Calculator.
7. Confirm each lead appears in the CRM and that unauthenticated visitors cannot read leads.

The publishable key in supabase-client.js is intended for browser use and is protected by the database RLS policies.
