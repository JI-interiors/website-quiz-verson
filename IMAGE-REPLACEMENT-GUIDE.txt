LINVA INTERIORS — IMAGE REPLACEMENT GUIDE

Each Design Ideas category now contains 6 separate image slots.

Categories:
- Kitchen
- Bedroom
- Living Room
- Bathroom
- Pooja Room
- TV Unit
- Kids Bedroom
- Dining Room
- Balcony

The current pages use dummy images so the VS Code preview never shows broken images.

To replace an image:
1. Put your real image inside /images/design-ideas/<category>/
2. Open that category HTML file in /design-ideas/
3. Find the relevant <article class="gallery-card">
4. Change only its <img src="..."> path.

Recommended file format:
- WebP
- JPG/JPEG also works
- Keep images reasonably compressed for fast loading.

Example:
../images/design-ideas/kitchen/kitchen-01.webp

You can add more gallery cards by copying an existing gallery-card block.
